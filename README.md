# WINDOWS 11 WEB SANDBOX

Playton Corporation · версия 0.1.0

Браузерная имитация Windows 11 для экспериментов с виртуальной системой. Это не продукт Microsoft, не эмулятор процессора x86 и не копия Windows в бинарном виде. Все модели файлов, интерфейс, обои, иконки и звуки созданы специально для симулятора.

## Запуск

    npm ci
    npm test
    npm run dev
    npm run build

Производственная сборка: dist/. Для GitHub Pages выберите в Settings → Pages → Source: GitHub Actions. Workflow находится в .github/workflows/pages.yml. Относительные пути поддерживают размещение в подпапке репозитория. Доступность Pages для приватного репозитория зависит от тарифа и настроек GitHub; не меняйте видимость без согласия владельца.

## Архитектура

- src/model.ts: изменяемая виртуальная файловая система, реестр, учётные записи, метаданные и подписи системных компонентов, проверка загрузки, восстановление, контрольные точки и оборудование.
- src/processes.ts: таблица виртуальных процессов, проверка запуска, результат остановки процессов.
- src/terminal.ts: собственный интерпретатор команд CMD и части PowerShell; не запускает команды на хосте.
- src/storage.ts: IndexedDB, импорт и экспорт.
- src/kernel.worker.ts: фоновая диагностика, размер и количество файлов.
- src/main.tsx: оболочка, менеджер окон, загрузка, UEFI, WinRE, уведомления и рабочие столы.
- src/fileApps.tsx, src/systemApps.tsx, src/extraApps.tsx: 27 приложений.
- public/sw.js: Service Worker и офлайн-кэш. manifest.webmanifest: PWA.

## Эксперимент

1. В «Восстановление» создать контрольную точку.
2. В «Параметры → Учётные записи» выбрать SYSTEM либо TrustedInstaller, подтвердить виртуальный UAC.
3. В Проводнике перейти в C:/Windows/System32.
4. Изменить виртуальный критический файл. Например, испорченный ntoskrnl.exe вызывает синий экран после перезапуска. Отсутствие explorer.exe приводит к чёрному экрану после завершения оболочки или перезапуска.
5. В среде восстановления выбрать восстановление при загрузке или контрольную точку.

## Изоляция и ограничения

- Никакие виртуальные команды, параметры UEFI или права не обращаются к ОС устройства. Все изменения производятся над объектами модели.
- Файлы .exe, .dll, .sys и .efi — исключительно метаданные и виртуальные маркеры, не настоящие бинарные файлы. Нельзя запускать нативные EXE/MSI, драйверы либо Windows-программы.
- Установленные HTML-приложения работают в sandboxed iframe с непривилегированным origin, ограниченной CSP, без доступа к виртуальному хранилищу.
- Встроенный Edge — безопасная оболочка адресной строки, истории и закладок; посещение реальных сайтов происходит в отдельной вкладке браузера.
- Мониторинг ЦП, RAM, SSD и проверки безопасности — модели виртуальных показателей, не датчики настоящего устройства. Ножницы создают схематичное изображение виртуального рабочего стола.
- IndexedDB может очищаться браузером. Регулярно экспортируйте файл резервной копии.
- На iPhone откройте Safari, нажмите «Поделиться» → «На экран Домой». Полноэкранный режим зависит от браузера. При вводе текста используется системная экранная клавиатура.
